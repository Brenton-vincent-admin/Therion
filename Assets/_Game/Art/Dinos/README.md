| `carnotaurus` | 8 m long, 3 m at the head | 9,500 / 4,000 / 1,500 | 2.0 m/s over 1.2 s, 9.0 m/s over 0.62 s |

Each folder holds `<id>.fbx`, `<id>_Albedo.png` (neutral, for the recolour shader), `<id>_Normal.png` and `<id>_Mask.png`
(R belly, G accent: back ridge, claws, eye ring, horns; B eyes; A pattern area, 0 on teeth, claws and eyes).

Import notes (not yet verified in the Unity editor):
- Metres, Y up, facing +Z, origin on the ground between the feet, `adultModelScale = 1`.
- Generic rig, root bone `Root`. Turn on Bake Axis Conversion if the rig root shows a -90 degree rotation.
- Meshes are named `<id>_LOD0/1/2`, one material slot, UV0 only.
- FBX takes are named `Rig|<Clip>`: Idle, Walk, Run, Rest (loop) and Attack, Ability, Eat, Drink, Hurt, Faint (one-shot).
  Ability is a roar for `trex` and the Bull rush for `carnotaurus`. Clips are in place, with no root motion.
- Mark `<id>_Normal.png` as a normal map and `<id>_Mask.png` as linear (sRGB off).
